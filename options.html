GitHub Repository Configuration

Configure your GitHub credentials so OpenJam can automatically upload session recording HTML reports and generate public GitHub Pages preview links.

How it works:
  • Reports are uploaded via GitHub API to docs/reports/{prefix}-{timestamp}.html in the target repository.
  • Once uploaded, the public URL https://{owner}.github.io/{repo}/reports/{prefix}-{timestamp}.html is automatically copied to your clipboard.
  • Ensure GitHub Pages is enabled in your repository's Settings > Pages with /docs folder as the source.
